## Overview

**CS2 Cheat Suite** is a Counter-Strike 2 utility project concept focused on game customization, visual settings, configurable assistance tools, and profile management.

Instead of separating different configuration categories into multiple standalone interfaces, the suite brings them together under a single Windows-oriented control panel.

The project covers several frequently discussed CS2 tool categories:

- Aimbot configuration
- ESP and visual overlays
- SkinChanger customization
- Visual preferences
- Configuration profiles

The interface is organized around separate modules, allowing users to navigate different settings without unnecessary complexity.

**Important:** This README describes the intended tool categories and interface design. It does not verify that a particular downloadable build implements every feature.

### 👁️ ESP & Visual Overlays

ESP (Extra Sensory Perception) refers to tools that display additional information about game entities.

Common terminology associated with this category includes:

| Feature | Description |
|---|---|
| Player ESP | Additional player information overlays |
| Box ESP | Rectangular entity indicators |
| Skeleton ESP | Character bone or pose visualization |
| Weapon ESP | Weapon-related display information |
| Distance ESP | Distance labels for entities |
| Radar | Alternative positional visualization |
| Visibility Indicators | Visual distinction between entity states |

Actual access to game information and rendering support depend on the implementation.

### 🎨 SkinChanger

SkinChanger is a customization category focused on weapon and cosmetic appearances.

Typical areas of interest include:

- Weapon skin selection
- Cosmetic previews
- Knife appearance customization
- Glove appearance customization
- Finish and style browsing
- Preset organization

Cosmetic preview tools and actual in-game modifications are different capabilities.

The availability of any in-game appearance changes must be verified against the installed software version.
